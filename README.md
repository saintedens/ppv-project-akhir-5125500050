# Kalkulator IPK — Project Akhir Praktikum Pemrograman Visual

Aplikasi web interaktif untuk menghitung Indeks Prestasi Kumulatif (IPK), mengelola daftar mata kuliah beserta bobot SKS, dan menyimpan data secara otomatis di peramban.

**Repositori:** https://github.com/saintedens/ppv-project-akhir-5125500050

## Cara Menjalankan

1. Kloning repositori:
   ```bash
   git clone https://github.com/saintedens/ppv-project-akhir-5125500050.git
   ```
2. Buka folder di Visual Studio Code.
3. Jalankan `index.html` dengan ekstensi **Live Server**, karena aplikasi memakai ES Modules dan tidak bisa dibuka langsung lewat file://.

## Struktur

- `src/` berisi modul JavaScript (`main.js`, `state.js`, `ui.js`, `storage.js`, `komponen.js`)
- `docs/` berisi charter, roadmap, dan halaman konsep produk (`docs/konsep/`)
- `MODULE_MAP.md` berisi peta modul
- `CHANGELOG.md` berisi riwayat versi
